# 二维平台五场独立物理实验

本目录属于“毕设仿真”，来源 d3c0f17 加模型坐标系兼容修正；正式批次 session_004。结果和边界见 [结果归纳](结果归纳.md)。原始请求、控制历史、DataFlash 和全频率物理位姿留在 Ubuntu，本机另有全量归档。
