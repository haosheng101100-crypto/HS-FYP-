# 候选轨迹搜索与执行说明

当前算法根据因果观测预测平台运动，对有限个接触时间分别求解带物理、几何和误差余量约束的分段七阶 Bézier 轨迹，再从通过审计的轨迹中选择最低评分者。评分保持为轨迹代价 + 0.5 × 时长；重规划时另加 2 × 相对首次承诺接触时刻的偏移平方。

轨迹代价由正权重的落点偏移平方和 jerk、snap 平方积分组成，数学下界为零。因此每个候选都可在求解前算出评分下界。在已有审计通过的轨迹后，只有某候选的下界严格高于当前最佳评分并超过数值缓冲时，才跳过该次求解。记录状态为 `SCORE_BOUND_PRUNED`，含下界和当前最佳评分；跳过不代表不可行。接近相等的候选仍求解，保留原升序及同分时较早候选的选择规则。

`BezierLandingPlanner.search(..., prune_score_dominated=False)` 可运行完整搜索用于对照。默认启用下界剪枝；候选时间集合、评分、飞机模型、控制参数与原轨迹审计保持。该下界依赖当前非负目标结构；以后加入负奖励或修改评分时，必须同步复核下界及回归测试。

报告的 `solved_candidates` 统计候选 `solve()` 的调用次数，其中包括在接触边界或几何预检阶段就被拒绝的候选；它不等同于底层锥优化器的实际调用次数。`score_bound_pruned_candidates` 统计因评分下界而跳过的候选数。

## 末段数值求解初始化

优化问题的 CVXPY DPP 模板继续复用，每次求解显式设置 `warm_start=False`，重新建立 Clarabel 数值求解器。CVXPY 模板的复用与 Clarabel 内部数值状态的复用是两件事；此设置保留前者。短时域的导数和目标系数随分段时长的负幂变化，长时域预热后直接更新旧数值求解器，在已保存请求中可复现迭代上限及数值错误。重新初始化数值求解器后，该请求能返回与独立冷问题一致的不可行状态。

目标函数、候选评分、约束、`max_iter=100`、`tol_gap_abs=1e-8`、`tol_feas=1e-8` 和求解后审计保持。数值错误仍记作 `SOLVER_ERROR`，迭代上限等状态仍拒绝返回轨迹；不会把数值错误改称不可行或默认接受。求解记录的 `solver_cache_policy` 标明 `fresh_numeric_solver_reused_dpp_template`。该修改不保证任意请求均可求解，也不证明候选族之外无可行轨迹。

更新后可运行 `python -m unittest discover -s tests -v`。新增数值回归覆盖长短时域切换、模板复用、世界平移、不可行后恢复可行求解及数值错误拒绝；`tests/fixtures/terminal_cache_transition.json` 是这些测试需要的最小数值输入，不含完整飞行记录。此次初始化修改完成的是离线数值验证；更新后的物理闭环表现需在新 session 中重新仿真和审计，历史物理结果对应其固定源码版本。

优化与控制保持异步：规划器请求未来接续状态，执行层继续跟踪已接受的有效轨迹；新结果必须通过原有时效、预测一致性与跟踪接续检查。临近接触时锁定轨迹和时刻，满足原捕获条件后交给原生 LAND。新轨迹迟到时仍拒绝；安全余量不足时仍抬升返航。本修改不改变未来接续提前量或迟到容限。

这里的最佳仅指当前有限候选、轨迹族、预测和评分下的最佳合格轨迹。减少求解次数不等于闭环鲁棒性保证，也不保证突变场景均可落台。目标平台仍为固定高度水平甲板；真机适配需另行验证。

算法主入口为 `landing/receding_landing.py`，执行与恢复为 `landing/receding_live.py`，仿真工作进程为 `tools/receding_planner_worker.py`。原 `frozen_source_v82`、`simulation/reference_cycle` 及旧物理记录是历史基线，不应覆盖。使用新算法做新仿真时，应复制当前主入口至实际部署包，创建独立 session 并核对代码哈希，沿用原接触、原生停转、支撑与退出审计。

Ubuntu 接续时，把当前 `landing/receding_landing.py` 复制到新部署包的同名位置，并更新新部署包的 `source_manifest.json` 中该文件的 SHA256。若监督器还根据某个预声明协议核对源码，应为新试验生成包含当前源码哈希的新声明，同时保持原控制配置和安全门限；原协议 v30 中的旧代码哈希用于历史基线，不能直接宣称它验证了新代码。之后先运行相关单元测试，再启动独立物理试验并重新审计。`simulation/operator_package/` 中的监督器路径仍需按目标机器配置。
