# 毕设移动平台降落演示

本机已验证的算法功能：X/Y/XY方向跟随平台；下降中平台换向后制止下降、重新跟随，再规划落台。采用4m脚底初始跟随净空专项，属于与原1.5m基础profile不同的初态。只用于声明条件下的仿真展示。

## 在这台Ubuntu电脑启动

在本目录打开终端，执行：

```bash
bash tools/start_functional_demo.sh all
```

只看一个方向，把`all`换成`x`、`y`或`xy`。启动后会自动起飞和执行演示，原生面板保留暂停、继续等按钮。X/Y/XY依次在全新场景运行。首次提示时输入本机管理密码；脚本不保存密码。

当前桌面图形连接、容器和输出目录每次新建；不需要重新登录GitHub。视频和完整运行记录保存到本机工作区`outputs/毕设功能演示_时间_编号/`，不会覆盖历史场景。需要正常结束时，使用原生面板关闭，系统会按已有LAND/解除锁定流程处理；不要直接强杀飞控。

这份入口适用于已部署的本机Ubuntu环境。它需要本机`hs-fyp-demo:20261102-verified`容器镜像，以及工作区`work/reacquisition_20261102/deployment/`的原模型、依赖和固定固件。GitHub源码包不包含这些大体积运行依赖，也不声称拷到任意新电脑即可运行。若工程位置改变，可设置`HS_WORKSPACE`指向包含上述`work/`的工作区。
