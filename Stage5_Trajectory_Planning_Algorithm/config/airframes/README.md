# 机型参数记录

`iris_fixed_gimbal_sim.json` 仅记录当前固定云台 Gazebo Iris 的参数来源与验证范围。刚体试验只验证零相位、无气动力的装配响应，飞行有效惯量和执行器参数仍待辨识。

`real_airframe_pending.json` 为待定真机配置，未知项为空，禁止自动用仿真值回填。用户已明确真实机型可能与仿真不同。

真实脚底几何模块 landing/contact_geometry.py 和离线轨迹审计已显式读取仿真配置；必要几何或坐标定义为空时会报错。这两个文件尚未接入历史基线飞行控制器；历史固定常数保留以复现实验。后续动力学模块也应显式选择配置，并拒绝依赖的必要参数为空的情况。
